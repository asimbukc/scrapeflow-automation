Scrapeflow is a workflow based web scraping solution where each node represents a specific operation.
You can design your own custom workflow by connecting different nodes, then run it
manually whenever needed or schedule it to run automatically at predefined intervals.

Built with React-Flow, Nextjs, Node.js (Express) and MongoDB, the platform provides a visual workflow builder, workflow execution engine, scheduling capabilities, data storage and scalable API architecture for managing complex web scraping tasks efficiently.
